## Patterns of the Top 10%

### Pattern 1: Named, Specific Testimonials
TBD Building's testimonials include full names, project addresses, and repeat-client mentions. Generic "satisfied client" quotes don't convert. The top sites use real names + real locations.

### Pattern 2: Founder-First Personal Brand
The highest-converting sites (TBD, Saray) lead with the founder's name, face, and story — not the firm. "Zach Carpenter" and "Thuraya Ghanem" are the product. Michael already does this well.

### Pattern 3: Clear 3-Phase Process Framework
RWB (Design/Build/Live), Michael (Vision/Execution/Completion), Kachay (Plan/Build/Lead) — all top sites use a numbered process to reduce client anxiety and demonstrate systematic thinking.

### Pattern 4: Qualification-First Contact
The best sites don't have generic "contact us" forms. They gate by budget and project type to pre-qualify leads. Michael's discovery form already does this — it's a competitive advantage.

### Pattern 5: Geographic + Niche Specificity
Top performers own a specific geography + niche combination: "South Florida luxury coastal", "LA architectural masterpieces", "Rancho Santa Fe custom builds". Michael's "California to Caribbean" is broad — tightening to "hospitality + ultra-luxury residential" would sharpen positioning.

## Recommended Design Direction (for Build Brief)

**Colors:** Keep `#050505` background + gold accent. Add warm stone `#E8E0D0` for light sections.  
**Typography:** Inter (current) is correct. Consider adding a display serif (Cormorant Garamond or Playfair Display) for section titles only.  
**Photography:** Full-bleed project photography is the #1 gap vs. competitors. Every project needs a hero image.  
**Animation:** The scroll-sequence canvas is a genuine differentiator — no competitor has anything close. Keep and enhance.  
**Social Proof:** Add named testimonials with project specifics (like TBD Building). Add a "repeat clients" signal.  
**Hospitality:** Create a dedicated hospitality section — the pool project + resort positioning is underutilized.
